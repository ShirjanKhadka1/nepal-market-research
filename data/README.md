# `data/` — empty by design, for now

This folder is reserved for datasets that meet the repo's own rules:
every figure with a named public source, period, and page/section, on the
same page as the figure; no scraped data presented as official; no
invented prices.

**Status, 28 Oct 2026: no dataset has been added yet.** The folder is
empty because no dataset has met that standard yet — not because data
is hidden elsewhere in this repo.

A dataset belongs here only when it ships with, in the same file or an
accompanying note: its source (publisher + URL or publication), its
period, its licence/terms for reuse, and the date it was retrieved.
Until then, the case studies in `case-studies/` cite their sources
in-text (starting with Bottlers Nepal (Terai), 39th annual report,
FY 2081/82, inputs only).

> to buy or sell any security.
